## 筛选与标注标准需要区分

自然语言初筛要求人源 PSC 体外分化，并允许表达谱或染色质测序，初次结果为 9 纳入、1 排除。随后运行的默认 GSE 标注方案要求单细胞数据和正常遗传背景，得到 3 纳入、7 排除。两阶段标准不同，不能把结果变化当成筛选准确率，也不能把默认方案自动当作最初自然语言标准。

GSE276596 的初筛解释存在实质遗漏，已作为补充元数据的回归样本。默认方案因其 bulk RNA-seq 和遗传编辑背景而排除，与“仅小鼠”是不同理由。用户选用的 README 主图保留了当时状态，不会修改图片中的历史判断来掩盖问题。

## 复核边界

PDF 文件有效、模型返回 JSON、原文片段匹配、实验条件解释正确，是不同层次的验证。程序可检查 24 列字段、时间一致性、GSM 归属、证据页码和原文匹配；逐行剂量、时间、组别及引用关系仍需要原文复核。

本次已经发现需要继续处理的质量限制：

- 双栏 PDF 的文本可能交错。GSE239550 的长引文虽对应可见原文，仍可能因双栏顺序或行末断词而无法通过逐字匹配；不能把这些警告自动清空。
- 分块结果合并目前去除完全重复事件，但不会自动解决跨块的重复来源请求或矛盾说明。某块不包含 Methods 不等于整篇论文缺少 Methods；需要对照全部材料复核。
- 有效证据片段只说明片段确实存在，并不能证明其支持该行每个字段，也不等于完成 GSM 映射。

正文若将关键步骤指向引用或补充材料，应保留 `needs_sources`。新 GSM 任务中，没有明确样本映射时必须保留待补证据，不能把 `GSM_id=NA` 标记为已复核；旧文献级结果仍允许保留 NA。草稿导出不等于已复核导出，不应把缺失信息补成推测配方。
