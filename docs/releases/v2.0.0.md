# GEO Screener v2.0.0

将筛选文献转换为按 GSM 样本组织、可追溯证据的 Protocol 工作流，同时保留原有检索、筛选、标注和文献库功能。

## 本版更新

- 每个 GSM 独立提取一套适用 protocol，分别重试、修订、复核和导出；同篇论文共享来源材料，旧文献级结果保留。
- 获取正文 Methods 和补充材料，支持 PDF、TXT、Markdown、DOCX、XLSX、CSV、TSV、ZIP；依据明确引用关系使用补充来源。
- 随包提供 perturbation-extractor、protocol-chain-annotator 和默认 prompt。新用户无需个人 skill 文件；空私有目录可回退到内置模板。
- 校验 GSM 归属、时间、页码和逐字证据；未复核或来源不足的结果保留为草稿。模型调用不设置固定输出 token 上限。
- 中英文界面、完整使用指南、清爽科研工作台，以及原生 2× 像素密度 PNG 功能截图。
- OrcaRouter 位于模型列表首位并标为推荐；保留 DeepSeek / OpenAI-compatible 配置。
- 修复 PMC PDF 获取、筛选上下文和标注进度计数等问题。

## 验证

- 全新 Python 3.11 环境、发布依赖：146 项后端测试通过；8 项前端测试通过。
- 新数据库、空私有 prompt 目录、无 API 配置的新账号验证默认模板可用。
- 固定 10 篇文献：10/10 正文成功下载和解析，Methods / 补充材料完成获取。
- 按小规模要求，8 个 GSM 完成实际处理：6 个返回提取结果，2 个因样本对应证据不足保留待补来源；1 个完成独立人工复核与浏览器 TSV 导出。机器草稿不等于已验证实验方案。

## 安装与升级

下载本版本 Source code，使用 Python 3.11，按 [English README](https://github.com/lzzsh/GEO_Screener/blob/v2.0.0/README.md) 或[中文 README](https://github.com/lzzsh/GEO_Screener/blob/v2.0.0/README.zh-CN.md) 启动。先备份已有数据库；迁移为新增表/字段，保留旧任务与修订。

注册自己的账号并配置 API 服务。发布包不包含开发者账号、API Key、研究数据库或私有数据。原 v1 快照仍保存在 `v1-baseline-20260910`。

来源映射不清楚、扫描件、不可解析附件或缺失引用仍需人工补证；请对照原文复核剂量、时间与样本分支。[完整验证说明](https://github.com/lzzsh/GEO_Screener/blob/v2.0.0/docs/V2_LIVE_VALIDATION.md)。
