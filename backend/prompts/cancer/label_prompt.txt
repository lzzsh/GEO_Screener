纳入标准
本研究仅纳入"人源癌症组织或细胞系的转录组数据"，具体要求如下：

样本来源

必须为人源原发肿瘤组织、癌症细胞系或循环肿瘤细胞

来源需明确诊断为癌症（任何类型），或为已建立的癌症细胞系

允许包括癌旁正常组织作为对照，但必须有明确的癌症样本

排除非癌症疾病样本、健康志愿者无癌症关联的样本

数据类型

必须为转录组数据，包括 bulk RNA-seq、scRNA-seq、空间转录组、microarray

排除全基因组测序、外显子测序、甲基化芯片、蛋白质组学等非转录组数据

实验设计

可接受任何实验处理（药物处理、基因敲除/过表达、放疗等），但必须有对照或基线表达数据

可接受任意研究目的，如分子分型、耐药机制、转移机制、预后分析

不要求 GEO 明确写出详细实验方案；只要文本支持其为癌症相关转录组数据即可

样本状态

可接受冷冻、FFPE、新鲜样本

排除非人源样本（如小鼠异种移植模型中的鼠源数据，但人源细胞部分可接受）

GEO 元数据
GSE_ID: {dataset_id}

Title:
{title}

Summary / Description / Overall Design:
{description}

输出要求
请严格输出 JSON，不要输出 Markdown，不要输出代码块，不要输出 JSON 之外的任何文字。
不要输出 <think>、分析过程、解释、前言或后记。

JSON 必须使用以下结构：

{
"GSE_ID": "{dataset_id}",
"reasoning_text": "一整段连续中文推理文字，必须按固定顺序依次覆盖：样本来源、数据类型、癌症类型、实验处理、样本状态、最终判断；可以在同一段中使用"样本来源：""数据类型：""癌症类型：""实验处理：""样本状态：""最终判断："作为句内标签；不要分条、不要分块、不要按 1-5 点输出",
"final_conclusion": "可用 / 不可用 / 待确认",
"癌症类型": "",
"数据模态": "",
"样本类型": "",
"实验扰动": "",
"数据平台": "",
"是否提供原始测序数据": ""
}

判定规则
final_conclusion 只能是"可用"、"不可用"或"待确认"

只有当样本来源、数据类型、癌症类型、实验处理、样本状态均明确符合时，才能判定为"可用"

任一关键项为"不符合"，必须判定为"不可用"

任一关键项为"信息不足"，且没有明确排除证据时，必须判定为"待确认"

同时存在"不符合"和"信息不足"时，优先判定为"不可用"

reasoning_text 必须是一整段连续文字，不要分条、不要分块、不要按 1-5 点输出

reasoning_text 必须按固定顺序依次覆盖：样本来源、数据类型、癌症类型、实验处理、样本状态、最终判断

可以在同一段中使用上述句内标签，但这些标签之间不能换行或拆成列表

reasoning_text 每个判断点都需引用提供的 GEO 元数据原文关键词作为证据；若某点证据不足，直接在对应位置写"信息不足"

reasoning_text 必须客观、简洁、学术化

六个简短标注字段只填标准化短词或短语，不写推理；没有原文证据时必须填空字符串

"癌症类型"优先填写原文明确的癌症名称，如乳腺癌、肺腺癌、胶质母细胞瘤；不明确则为空字符串

"数据模态"填写 bulk RNA-seq、scRNA-seq、spatial transcriptomics、microarray 等；无明确证据则为空字符串

"样本类型"填写 tumor tissue、cell line、CTC、normal adjacent tissue 等；无明确证据则为空字符串

"实验扰动"填写 drug treatment、CRISPR、overexpression、knockdown 等；无扰动则为空字符串

"数据平台"填写 Illumina、Affymetrix、10x Genomics、Nanostring 等；无明确证据则为空字符串

"是否提供原始测序数据"只填写"是""否"或"不明确"；无明确证据则为空字符串
