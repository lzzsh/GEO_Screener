{{ t('开始检索') }} ↗

03{{ t('复核筛选结果与样本标注') }}

{{ t('在任务详情中查看纳入、排除、不确定的判断、理由和标签。模型置信度不是结论正确的保证；优先检查不确定项、缺少信息的记录以及与你的规则冲突的结果。') }}

{{ t('需要样本级分析时，再读取 GSM 信息并完成 GSM 标注。GSE 是数据集层级，GSM 是样本层级；不要把整篇文章的处理条件直接赋给每个 GSM。人工修订后检查保存结果。') }}

{{ t('文献库用于整理收藏的数据集及其标注；任务 CSV 用于导出筛选和标注结果。这些功能可独立使用，之后也可以继续进行 Protocol 提取。') }}

{{ t('「用文章重新校准」属于原有筛选流程，会基于文章重新评估筛选结果；它与 Protocol 提取是两个操作。Protocol 提取本身不会修改原任务的筛选判断或标签。') }}

{{ t('查看筛选任务') }} ↗

04{{ t('选择文献并补齐来源材料') }}

{{ t('在筛选任务详情的蓝色操作区，使用「提取 Protocol（已选数量）」或「全部已纳入文献」。后一项包含该任务所有纳入记录，不受当前表格分页限制。请先确认选择范围。') }}

{{ t('新建 Protocol 任务后，左侧按 GSM 样本展开，中间独立提取和复核，右侧查看来源证据。同一文献共享 Methods 与补充材料，每个 GSM 保留自己的条件、采样时间和修订版本。') }}

{{ t('先尝试「获取 Methods 与补充材料」。系统会复用已有 PDF，并根据明确的文章关联收集 Methods 和可用补充文件。若关联了多篇文章、下载失败或只得到摘要，请核对 PMID / DOI，并上传正确材料。') }}

{{ t('支持 PDF、UTF-8 TXT / MD / CSV / TSV、DOCX、XLSX 和 ZIP；每份最多 30 MB、PDF 最多 300 页，每条记录最多手动上传 20 份材料。系统自动收集同篇 Methods 与可用补充文件，覆盖清单显示模型输入。扫描件或内嵌图像仍需 OCR 或人工核对。') }}

{{ t('上传时区分正文、补充材料和引用来源。若目标文章沿用另一篇文章的方法，需要补充被引用的方法，并注明引用或采用关系。当前不会自动追完外部引用链。') }}

{{ t('查看 Protocol 任务') }} ↗

05{{ t('提取、补充来源与重试') }}

{{ t('有可用材料后，对单篇文献开始提取，或批量提取待处理项。模型会读取材料的逐页文本，提出实验组、扰动事件、时间、剂量和对应的原文证据。') }}

{{ t('「等待材料」表示还需添加可读来源；「排队中 / 获取材料中 / 提取中」表示处理中；「草稿」表示已经有结果但尚未人工复核。') }}

{{ t('「需要补充来源」表示引用配方或材料不完整，请根据待补来源清单补齐后重新提取。「未找到 Protocol」只表示当前材料没有找到可提取方案，不代表该研究一定没有实验方法。') }}

{{ t('失败时先阅读错误信息，检查模型连接、文件文本和材料是否完整，再重试。服务重启后一直停留在处理中且超过 20 分钟无进度的记录，可以重试。不要把失败或截断的响应当成完整结果。') }}

06{{ t('按证据复核并保存修订') }}

{{ t('逐行检查实验组、GSM 映射、阶段、扰动名称、工作浓度、开始 / 结束时间、培养基和采样时间。点击编辑记录查看四组字段，并对照右侧逐页文本；涉及表格、图注或排版时打开原文件核对。') }}

{{ t('每个事件都需要可在指定材料页码中找到的原文片段。系统可检查片段是否存在、字段格式和时间关系，但不会保证每个剂量或生物学解释都正确；这些内容仍需人工判断。') }}

{{ t('「保存修订」会创建新的人工修订版本；「保存并标记已复核」还要求解决所有阻断错误。一般缺失值可能只是提示，仍可保留为 NA，但应明确哪些信息没有证据。') }}

{{ t('重新提取会增加机器提案，并保留当前人工修订。通过结果版本选择器查看新提案；要采用它，需查看并保存为新的人工修订。两个窗口同时编辑发生冲突时，先记录本地修改，再刷新载入最新版本。') }}

07{{ t('Protocol 填写规则') }}

{{ t('一行描述一个实验组 / 样本在一个时间窗口中的一个扰动事件。不同实验组、剂量或时间窗口分别记录；不要把多个方法混成一个配方。') }}

{{ t('未知数值统一填写 NA。新任务中的 GSM_id 必须对应当前目标样本；映射不明确时保留待补证据，不能标记已复核。每个 GSM 使用一套适用流程，不混合不同处理分支。PubChem / ChEMBL 编号没有来源支持时保留 NA。') }}

{{ t('使用原文的最终工作浓度，区分母液浓度与工作浓度。长期不变的培养基添加物写入 Culture_medium；纯培养基阶段设置 Addition_context=basal medium，Pert_name 填 NA。') }}

{{ t('以分化或实验定义的 Day 0 为起点。time_unit 使用 days 或 hours；时间可写 D0 / D3 或 H0 / H24，并与单位一致。持续时间等于结束减开始；结束不能早于开始，也不能超过该样本采样时间。无法确定时使用 NA，不自行补算含糊的端点。') }}

{{ t('Stage_order 为正整数或 NA；Stage_name 和 Pert_type 必须使用导出规范中的枚举值。界面语言切换不会改写这些数据值。下方示例和字段参考保留原始字段名。') }}

{{ t('引用方法与目标文章发生冲突时，以目标文章明确说明的修改为准。找不到被引用的具体配方时，保留待补来源，不依赖模型记忆补齐。') }}

08{{ t('导出与交付') }}

{{ t('默认「导出已复核 TSV」只汇总各来源当前已复核的版本，保留固定 24 列顺序。「更多导出」提供草稿 TSV、证据 JSON 和待确认项 JSON；草稿文件应继续按未复核资料管理。') }}

{{ t('TSV 用于后续分析；证据 JSON 保存行号、实验组、来源页码及追溯信息；问题 JSON 保存待补材料、缺失值和阻断项。交付时建议同时保留 TSV、证据和原始材料，便于他人复核。') }}

{{ t('已复核代表通过当前结构校验并由使用者确认，不等于实验方案已经过生物学验证。用于实验设计或模型训练前，还应根据研究目标检查数据完整性和适用范围。') }}

{{ t('常见问题') }}

{{ t('为什么无法标记已复核？') }}

{{ t('展开待确认项，先处理阻断错误：缺少证据、页码或引文无法核实、时间冲突、GSM 不属于来源、非法枚举或引用材料未补齐。修订后再次保存；普通提示不一定阻止复核。') }}

{{ t('PDF 下载失败怎么办？') }}

{{ t('先核对文章身份，再从可获取的正文或作者材料中补充文件。自动下载不保证所有出版商可用，也不会绕过访问权限；扫描件需另行提供可检索文本。') }}

{{ t('为什么导出为空或比预期少？') }}

{{ t('默认导出只包含当前已复核版本；检查是否仍为草稿、是否有待补来源，以及提取结论是否有事件。需要查看未复核内容时，使用明确标注的草稿导出。') }}

{{ t('切换语言会翻译文献或改变模型输出吗？') }}

{{ t('不会。语言开关只切换界面说明、按钮和状态提示；文献原文、自定义标签、Protocol 值和导出字段保持原样。提取时使用当前模型和提取规则，不能把界面语言当成结果语言设置。') }}
